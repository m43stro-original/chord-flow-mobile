# ChordFlow — Android WebView для chords.m43st.ru

Минималистичное Android-приложение под названием **ChordFlow**, которое открывает сайт `https://chords.m43st.ru` напрямую во встроенном `WebView` без каких-либо дополнительных экранов, панелей или кастомного оформления, запрашивает разрешение на микрофон при запуске и использует фавикон сайта в качестве иконки приложения.

### Подтвержденные решения

> [!IMPORTANT]
> Учтены все правки и пожелания:

- **Название приложения**: `ChordFlow`.
- **Иконка приложения**: Используется оригинальный фавикон сайта `https://chords.m43st.ru`.
- **Никакого дополнительного дизайна или интерфейса**: Никаких кастомных экранов, шапок, баннеров или оверлеев — открывается исключительно сам сайт `https://chords.m43st.ru` на весь экран.
- **Доступ к микрофону**: При первом запуске запрашивается системное разрешение `RECORD_AUDIO`, а запросы микрофона от самого сайта (`RESOURCE_AUDIO_CAPTURE`) автоматически подтверждаются внутри `WebChromeClient`.
- **Удержание экрана**: Экран остается включенным (`FLAG_KEEP_SCREEN_ON`) все время, пока открыто приложение.

---

### 1. Обзор и основная концепция

- **Что делает приложение**: Сразу после запуска открывает `https://chords.m43st.ru` в полноэкранном `WebView` и обеспечивает работу микрофона для всех аудио-функций сайта.
- **Ключевая ценность**: Прямой доступ к сайту с домашнего экрана Android под именем **ChordFlow** с родной иконкой сайта и настроенными разрешениями микрофона.

---

### 2. Пользовательский опыт и интерфейс

- **Поведение при запуске**:
  1. При открытии **ChordFlow** сразу загружается `https://chords.m43st.ru` на весь экран (с учетом системных отступов Safe Area, чтобы сайт не перекрывался статус-баром или системной навигацией).
  2. При первом запуске система показывает стандартное окно Android для разрешения доступа к микрофону (`RECORD_AUDIO`).
  3. Когда страница на сайте обращается к микрофону (`getUserMedia`), `WebView` автоматически передает ей доступ без повторных диалогов.
  4. Системная кнопка/жест «Назад» работает для навигации назад внутри сайта (`webView.goBack()`), если есть история переходов.

---

### 3. Ключевые технические решения

- **Решение 1: Прямой WebView без надстроек**
  - *Выбранный подход*: Единственный компонент на экране — `AndroidView` с `WebView`, настроенным на `https://chords.m43st.ru` (`javaScriptEnabled = true`, `domStorageEnabled = true`, `mediaPlaybackRequiresUserGesture = false`).
  - *Почему*: Полностью соответствует требованию открыть только сам сайт без постороннего UI.
- **Решение 2: Фавикон сайта как иконка приложения**
  - *Выбранный подход*: Загрузка актуального фавикона с `https://chords.m43st.ru` и установка его в качестве адаптивной иконки лаунчера (`ic_launcher` / `ic_launcher_round`).
  - *Почему*: Обеспечивает узнаваемость приложения **ChordFlow** в полном соответствии с веб-версией.
